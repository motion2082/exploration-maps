## What's new in 1.0.0

The first release of **Exploration Maps**, Paul D's fork of Nick Milo's Maps of the Ideaverse (built on 0.8.22). Plugin id `exploration-maps`.

**New names, so each map says what it shows**
- **Levels** (was Emergence): notes sorted by how linked they are, from unlinked notes up to home notes and hubs.
- **Cosmos** (was Ideaverse): your whole vault as a ball of notes you can turn.
- **Work Modes** (was Sensemakers): four corners in plain words: Thinking, Drafting, Organising and Shipping. Left to right is taking in → putting out; bottom to top is loose → structured.
- **Graph** (was Obsidian): the graph view, drawn with the level symbols.
- The plugin's own name, watermark, tab title and capture credit now read Exploration Maps. Your saved views keep loading.

**Work Modes works in any vault**
- New **Settings → Work Modes folders**: tell it which folders hold your journal, inbox, sources, main notes and projects. Before, it only knew the LYT folder names (Calendar, Efforts, Atlas, +), so in other vaults most notes sat near the middle. ARC uses the same folders. The defaults are still the LYT folders.

**Clearer legend and panel**
- Link lines read **links up a level** and **links down a level**.
- **Other properties** now names the properties your own vault links with most, instead of a fixed example list.
- Level names on the Levels map move clear of the Legend and Animations tabs.
- In the note panel's lists, **Ctrl-click** (⌘-click on Mac) or **middle-click** a note to open it in a new tab. A plain click still takes you to it on the map.
